# Debug, Deploy, Adventure, Repeat assets

Before generating or revising any image or animation for this portfolio, read and apply the **Style bible** in `../prompts/asset-prompts.md`. It is the standing art direction, including the hard rules and the designs for the hero, Muffins, and recurring props. Follow any explicit exceptions in the current asset request.

Reference photos are in `raw/reference/`. The trial anime images named on the prompt cards are in the project folder one level above `assets/`. For the hero and Muffins, use the relevant photos and model sheets. The model sheets are `raw/reference/REF-01-hero-model-sheet.png` and `raw/reference/REF-02-muffins-model-sheet.png`. When generating a model sheet, use the references specified on its prompt card.

Use the requested filenames and output locations. For prompt-pack assets, follow the paths on their cards. For animations, include a ZIP of the individual PNG frames alongside the animation.
